:::tip My tip

:::

## Ganti `Password ?`

**`Petunjuk melakukan ganti password :`** 

- **`Tekan tombol`** ***Profile*** pada logo bisnis seperti pada Gambar 5.

<img src="/img/login 3.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 5 Tombol Profile
</p>

- **`Pengguna akan diarahkan ke halaman Profile`**, lalu arahkan selektor pada fitur ***Security*** seperti pada **Gambar 6**.

<img src="/img/login 4.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 6 Format Security
</p>

|Isian|Deskripsi|
|--|--|
|Current Password|Password saat ini
|New Password|Password baru
|Confirm Password|Konfirmasi password baru

- **`Isilah data perubahan password`**, lalu tekan tombol ***Change Password***.
