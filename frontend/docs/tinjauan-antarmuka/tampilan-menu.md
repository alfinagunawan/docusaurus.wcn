## Tata Letak Tampilan Menu

<img src="/img/navigasi 2.png" alt="Deskripsi gambar" class="left"  />

::::note Navigasi 

**`#1 Navigasi Samping (Sidebar Menu)`** : Form informasi akun miliki pengguna.

**`#2 Tombol Menambah Data`**  : Pengguna akan diarahkan ke halaman menambah data.

**`#3 Tombol Download`** : Mengunduh data dalam format Excel.

**`#4 Tombol Upload`** : Mengunggah data dalam format Excel.

**`#5 Tombol Filter`** : Pengguna akan diarahkan ke format penyaringan data.

**`#6 Tombol Reset Filter`** : Mengembalikan list data seperti semula.

**`#7 Tombol Aksi dengan Simbol Titik 3`** : Opsi fitur seperti Edit, Delete, dan lain sebagainya.
