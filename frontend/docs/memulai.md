# Memulai
:::tip Web akses
Mari mulai dengan ***mengunjungi halaman kami*** [ http://phibase.io/ ] 
:::

## Persyaratan Sistem 

- `Akses phibase.io` :
  - **CPU** : Intel i3 atau setara
  - **RAM** : 4GB atau setara
- `Instalasi Executor phibase.io (opsional)` :
  - **CPU** : Intel i3 atau setara
  - **RAM** : 8GB atau setara
- `Hardisk` : 500GB
  - **Sistem Operasi** : Windows 11
- `Perangkat Lunak` :
  - **Browser** : Chrome versi 119

## Persyaratan Executor

- `MongoDB` :
  - **Versi** : MongoDB >7 Community Version


## Petunjuk Instalasi

**`Akses phibase.io`** :
1. Buka tautan http://phibase.io/ di browser Chrome versi 119 atau lebih baru.
2. Masuk dengan akun Anda.
3. Mulailah menggunakan aplikasi!

**`Instalasi Executor phibase.io (opsional)`** :
1. Unduh file EXE dari tim support phibase.io.
2. Jalankan file EXE dan ikuti petunjuk di layar.
3. Hubungkan Executor mig.phibase.io ke perangkat keras, sensor, atau mesin produksi Anda.

:::info Executor phibase.io
Memungkinkan komunikasi otomatis antara **phibase.io >< perangkat keras** di lantai produksi.
Meningkatkan efisiensi dan otomatisasi proses manufaktur.
:::
