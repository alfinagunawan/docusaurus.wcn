Halaman Payment System dapat dilihat pada **Gambar 2.16.1**
:::

<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.16.1 Halaman Payment System
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah sistem pembayaran.|Tekan tombol Add Payment System.|
|Download|Mengunduh sistem pembayaran dalam format file .xls atau .csv.|Tekan tombol Download.|
|Upload|Mengunggah sistem pembayaran dari file dengan format .xlsx, .xls, atau .csv.|Tekan tombol Upload.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Edit|Menyunting sistem pembayaran.|Tekan tombol Edit pada kolom Action.|
|Delete|Menghapus sistem pembayaran.|Tekan tombol Delete pada kolom Action.|
|Multiple Delete|Menghapus beberapa sistem pembayaran sekaligus.|Pilih sistem pembayaran baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Payment System ?`

**`Berikut petunjuk dalam menambahkan Payment System :`**

1. **`Tekan tombol`** ***Add Payment System*** dan pengguna akan diarahkan pada halaman penambahan sistem pembayaran seperti pada **Gambar 2.16.2**.

<img src="/img/commerce/masterdata/term2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.16.2 Halaman Add Payment System
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Duplicate Payment System|Formulir Payment System akan terisi Otomatis berdasarkan data yang sudah terdaftar|Tekan tombol Duplicate Payment System|

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Name|Nama atau label dari sistem pembayaran.|Ya
|Code|Kode unik sebagai pengenal dari sistem pembayaran.|Ya
|Type|Jenis pembayaran yang digunakan.|Ya
|Description|Keterangan tambahan mengenai sistem pembayaran tersebut.|Tidak

2. **`Isilah data penambahan Payment System`** lalu tekan tombol ***Submit***.
