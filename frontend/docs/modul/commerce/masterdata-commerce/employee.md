|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah karyawan.|Tekan tombol Add Employee.|
|Download|Mengunduh karyawan dalam format file .xls atau .csv.|Tekan tombol Download.|
|Upload|Mengunggah karyawan dari file dengan format .xlsx, .xls, atau .csv.|Tekan tombol Upload.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Details|Melihat informasi terkait karyawan secara lebih rinci|Tekan tombol Details pada kolom Action.
|Edit|Menyunting karyawan.|Tekan tombol Edit pada kolom Action.|
|Delete|Menghapus karyawan.|Tekan tombol Delete pada kolom Action.|
|Multiple Delete|Menghapus beberapa karyawan sekaligus.|Pilih karyawan baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Employee ?`

**`Berikut petunjuk dalam menambahkan Employee :`**

1. **`Tekan tombol`** ***Add Employee*** dan pengguna akan diarahkan pada halaman penambahan karyawan seperti pada **Gambar 2.22.2**.

<img src="/img/commerce/masterdata/employee2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.22.2 Halaman Add Employee
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Duplicate Employee|Formulir Employee akan terisi Otomatis berdasarkan data yang sudah terdaftar|Tekan tombol Duplicate Employee|

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Name|Nama lengkap dari karyawan.|Ya
|Type| jenis peran atau fungsi utama dari seorang karyawan di dalam struktur organisasi perusahaan.|Ya
|Phone|Nomor telepon karyawan yang dapat dihubungi.|Tidak
|Email|Alamat email karyawan yang dapat dihubungi.|Tidak
|Note|Catatan terhadap karyawan.|Tidak

2. **`Isilah data penambahan Employee`** lalu tekan tombol ***Submit***.
