## Tambah `Target ?`

**`Berikut petunjuk dalam menambahkan target :`**

1. **`Tekan tombol`** ***Add Target*** dan pengguna akan diarahkan pada halaman penambahan target seperti pada **Gambar 2.18.2**.

:::note Target barang tertentu
Target dengan format barang tertentu dapat dilakukan dengan `menghilangkan centang pada kolom checkbox` dengan menekan kolom checkbox kembali.
- Berikut format target untuk **`barang tertentu`**.
:::

<img src="/img/commerce/masterdata/target2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.18.2 Halaman Add Target dengan ketentuan untuk item tertentu
</p>

- `Pada halaman add target dengan barang tertentu` terdapat penambahan fitur, antara lain sebagai berikut.

| Fitur | Deskripsi | Wajib Diisi |
| -------- | --- | --- |
| Item | Memilih item untuk dijadikan target | Ya |
| Start Date | Tanggal dimulai target (dengan ketentuan tanggal tidak boleh melebihi tanggal berakhirnya target) | Ya |
| End Date | Tanggal berakhirnya target | Ya |
| Checkbox All Item | Menentukan target untuk keseluruhan item atau tidak | Tidak |
| Type | Sistem akan menyediakan 2 tipe target, antara lain target berdasarkan **nominal**, maupun target berdasarkan **quantity** | Ya |
| Unit | Pilihan unit akan mengikuti tipe target yang dipilih. Bila pengguna menggunakan tipe target nominal, maka unit akan tersedia berupa mata uang. Dan bila pengguna menggunakan tipe target berupa quantity maka unit akan tersedia berupa satuan item. | Ya |
| Target | Total sasaran yang ingin dicapai | Ya |
| Tombol ‘+’ pada kolom action | Menambah item untuk dijadikan target | Tidak |

:::note Target barang keseluruhan
Dalam penambahan target pengguna dapat menentukan target, apakah target untuk `keseluruhan barang` ataukah target untuk `barang tertentu` saja.
- Berikut format target untuk **`keseluruhan barang`**.
:::
