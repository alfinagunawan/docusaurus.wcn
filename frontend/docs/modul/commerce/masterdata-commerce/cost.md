|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah biaya/pengeluaran.|Tekan tombol Add Cost.|
|Download|Mengunduh biaya/pengeluaran dalam format file .xls atau .csv.|Tekan tombol Download.|
|Upload|Mengunggah biaya/pengeluaran dari file dengan format .xlsx, .xls, atau .csv.|Tekan tombol Upload.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Edit|Menyunting biaya/pengeluaran.|Tekan tombol Edit pada kolom Action.|
|Delete|Menghapus biaya/pengeluaran.|Tekan tombol Delete pada kolom Action.|
|Multiple Delete|Menghapus beberapa biaya/pengeluaran sekaligus.|Pilih biaya/pengeluaran baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Cost ?`

**`Berikut petunjuk dalam menambahkan Cost :`**

1. **`Tekan tombol`** ***Add Cost*** dan pengguna akan diarahkan pada halaman penambahan biaya/pengeluaran seperti pada **Gambar 2.25.2**.

<img src="/img/commerce/masterdata/cost2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.25.2 Halaman Add Cost
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Duplicate Cost|Formulir Cost akan terisi Otomatis berdasarkan data yang sudah terdaftar|Tekan tombol Duplicate Cost|

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Name|Nama atau jenis biaya yang ingin dicatat.|Ya
|COA|Kode akun dari Chart of Accounts yang sesuai dengan jenis biaya tersebut.|Ya
|Nominal|Jumlah nilai biaya yang dikeluarkan.|Ya
|Note|Keterangan tambahan jika ada, seperti tanggal kejadian, detail lokasi, dll.|Tidak

2. **`Isilah data penambahan Cost`** lalu tekan tombol ***Submit***.
