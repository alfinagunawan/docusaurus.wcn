|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah Lokasi.|Tekan tombol Add Location.|
|Download|Mengunduh Lokasi dalam format file .xls atau .csv.|Tekan tombol Download.|
|Upload|Mengunggah Lokasi dari file dengan format .xlsx, .xls, atau .csv.|Tekan tombol Upload.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Edit|Menyunting Lokasi.|Tekan tombol Edit pada kolom Action.|
|Set as Default Address|menandai satu alamat sebagai alamat utama atau default dalam suatu entitas|Tekan tombol Set as Default Address pada kolom Action
|Delete|Menghapus Lokasi.|Tekan tombol Delete pada kolom Action.|
|Multiple Delete|Menghapus beberapa Lokasi sekaligus.|Pilih Lokasi baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Location ?`

**`Berikut petunjuk dalam menambahkan Lokasi :`**

1. **`Tekan tombol`** ***Add Location*** dan pengguna akan diarahkan pada halaman penambahan Lokasi seperti pada **Gambar 2.10.2**.

<img src="/img/commerce/masterdata/location2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.10.2 Halaman Add Location
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Duplicate Location|Formulir Location akan terisi Otomatis berdasarkan data yang sudah terdaftar|Tekan tombol Duplicate Location|

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Name|Nama atau kode identitas unik untuk Lokasi.|Ya
|Address|Alamat lengkap lokasi, bisa berupa gudang, kantor, pabrik, atau titik distribusi.|Ya
|Latitude|Koordinat lintang (garis horizontal di peta), biasanya dalam format desimal.|Tidak
|Longitude|Koordinat bujur (garis vertikal di peta), juga dalam format desimal.|Tidak
|Note|Catatan tambahan mengenai alamat tersebut.|Tidak

2. **`Isilah data penambahan Location`** lalu tekan tombol ***Submit***.
