**`Menu ini digunakan untuk mendefinisikan jenis-jenis pesanan (order) yang digunakan dalam proses bisnis perusahaan. `** 

Halaman Order Type dapat dilihat pada **Gambar 2.22.1**
:::

<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.22.1 Halaman Order Type
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah jenis pesanan.|Tekan tombol Add Order Type.|
|Download|Mengunduh jenis pesanan dalam format file .xls atau .csv.|Tekan tombol Download.|
|Upload|Mengunggah jenis pesanan dari file dengan format .xlsx, .xls, atau .csv.|Tekan tombol Upload.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Details|Melihat informasi terkait jenis pesanan secara lebih rinci|Tekan tombol Details pada kolom Action.
|Edit|Menyunting jenis pesanan.|Tekan tombol Edit pada kolom Action.|
|Delete|Menghapus jenis pesanan.|Tekan tombol Delete pada kolom Action.|
|Multiple Delete|Menghapus beberapa jenis pesanan sekaligus.|Pilih jenis pesanan baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Order Type ?`

**`Berikut petunjuk dalam menambahkan Order Type :`**

1. **`Tekan tombol`** ***Add Order Type*** dan pengguna akan diarahkan pada halaman penambahan jenis pesanan seperti pada **Gambar 2.22.2**.

<img src="/img/commerce/masterdata/order-type2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.22.2 Halaman Add Order Type
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Duplicate Order Type|Formulir Order Type akan terisi Otomatis berdasarkan data yang sudah terdaftar|Tekan tombol Duplicate Order Type|

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Name|Nama lengkap dari jenis pesanan.|Ya
|Usage|Mengelompokkan tujuan utama dari jenis order tersebut dalam sistem.|Ya
|Type|Menjelaskan bentuk atau karakter khusus dari order tersebut dalam alur bisnis.|Ya
|Note|Catatan terhadap jenis pesanan.|Tidak

2. **`Isilah data penambahan Order Type`** lalu tekan tombol ***Submit***.
