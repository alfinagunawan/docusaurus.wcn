|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah konversi satuan ukuran.|Tekan tombol Add Conversion UoM.|
|Download|Mengunduh konversi satuan ukuran dalam format file .xls atau .csv.|Tekan tombol Download.|
|Upload|Mengunggah konversi satuan ukuran dari file dengan format .xlsx, .xls, atau .csv.|Tekan tombol Upload.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Edit|Menyunting konversi satuan ukuran.|Tekan tombol Edit pada kolom Action.|
|Delete|Menghapus konversi satuan ukuran.|Tekan tombol Delete pada kolom Action.|
|Multiple Delete|Menghapus beberapa konversi satuan ukuran sekaligus.|Pilih konversi satuan ukuran baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Conversion UoM ?`

**`Berikut petunjuk dalam menambahkan Conversion UoM :`**

1. **`Tekan tombol`** ***Add Conversion UoM*** dan pengguna akan diarahkan pada halaman penambahan Konversi Satuan Ukuran seperti pada **Gambar 2.2.2**.

<img src="/img/commerce/masterdata/converuom2.png" alt="Deskripsi gambar" class="center" />

Gambar 2.2.2 Halaman Add Conversion UoM
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Duplicate Conversion UoM|Formulir Conversion UoM akan terisi Otomatis berdasarkan data yang sudah terdaftar|Tekan tombol Duplicate Conversion UoM|

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Product|
|Description|
|Type Conversion UoM|
|UoM|
|Factor|

2. **`Isilah data penambahan UoM`** lalu tekan tombol ***Submit***.
