:::note
**`Menu CoA (Chart of Accounts) biasanya digunakan untuk mendefinisikan daftar akun dalam sistem akuntansi perusahaan`**. 

Halaman CoA dapat dilihat pada **Gambar 2.1.1**
:::

<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.1.1 Halaman CoA
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah CoA.|Tekan tombol Add CoA.|
|Download|Mengunduh CoA dalam format file .xls atau .csv.|Tekan tombol Download.|
|Upload|Mengunggah CoA dari file dengan format .xlsx, .xls, atau .csv.|Tekan tombol Upload.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Details|Melihat informasi CoA secara detail.|Tekan tombol Detail pada kolom Action.
|Edit|Menyunting CoA.|Tekan tombol Edit pada kolom Action.|
|Delete|Menghapus CoA.|Tekan tombol Delete pada kolom Action.|
|Multiple Delete|Menghapus beberapa CoA sekaligus.|Pilih CoA baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `CoA ?`

**`Berikut petunjuk dalam menambahkan CoA :`**

1. **`Tekan tombol`** ***Add CoA*** dan pengguna akan diarahkan pada halaman penambahan CoA seperti pada **Gambar 2.1.2**.

<img src="/img/commerce/masterdata/coa2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.1.2 Halaman Add CoA
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Duplicate CoA|Formulir CoA akan terisi Otomatis berdasarkan data yang sudah terdaftar|Tekan tombol Duplicate CoA|

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Name|Nama akun. Digunakan untuk memberi identitas akun (contoh: Kas, Piutang Usaha, Pendapatan Jasa).|Ya
|Code|Kode unik akun, biasanya berbentuk angka atau kombinasi angka-huruf.|Ya
|Type|Jenis akun, biasanya mengacu pada kategori akuntansi (Asset, Liability, Equity, Revenue, Expense).|Ya
|Description|Penjelasan singkat tentang fungsi akun agar mudah dipahami pengguna lain.|Tidak

2. **`Isilah data penambahan CoA`** lalu tekan tombol ***Submit***.
