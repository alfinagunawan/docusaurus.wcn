|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah data sopir.|Tekan tombol Add Driver.|
|Download|Mengunduh data sopir dalam format file .xls atau .csv.|Tekan tombol Download.|
|Upload|Mengunggah data sopir dari file dengan format .xlsx, .xls, atau .csv.|Tekan tombol Upload.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Details|Melihat informasi data sopir secara detail.|Tekan tombol Detail pada kolom Action.
|Edit|Menyunting data sopir.|Tekan tombol Edit pada kolom Action.|
|Delete|Menghapus data sopir.|Tekan tombol Delete pada kolom Action.|
|Multiple Delete|Menghapus beberapa data sopir sekaligus.|Pilih data sopir baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Driver ?`

**`Berikut petunjuk dalam menambahkan Driver :`**

1. **`Tekan tombol`** ***Add Driver*** dan pengguna akan diarahkan pada halaman penambahan data sopir seperti pada **Gambar 2.23.2**.

<img src="/img/commerce/masterdata/driver2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.23.2 Halaman Add Driver
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Duplicate Driver|Formulir Driver akan terisi Otomatis berdasarkan data yang sudah terdaftar|Tekan tombol Duplicate Driver|

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Name|Nama lengkap driver. Digunakan untuk identifikasi.|Ya
|Phone|Nomor telepon driver. Untuk keperluan komunikasi (misalnya koordinasi pengiriman).|Tidak
|Email|Alamat email driver. Bisa digunakan untuk informasi resmi atau notifikasi.|Tidak
|Note|Catatan tambahan terkait driver, misalnya status SIM, pengalaman, area kerja, atau catatan khusus lainnya.|Tidak

2. **`Isilah data penambahan Driver`** lalu tekan tombol ***Submit***.
