|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah kategori.|Tekan tombol Add Category.|
|Download|Mengunduh kategori dalam format file .xls atau .csv.|Tekan tombol Download.|
|Upload|Mengunggah kategori dari file dengan format .xlsx, .xls, atau .csv.|Tekan tombol Upload.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Edit|Menyunting kategori.|Tekan tombol Edit pada kolom Action.|
|Delete|Menghapus kategori.|Tekan tombol Delete pada kolom Action.|
|Multiple Delete|Menghapus beberapa kategori sekaligus.|Pilih kategori baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Category ?`

**`Berikut petunjuk dalam menambahkan Category :`**

1. **`Tekan tombol`** ***Add Category*** dan pengguna akan diarahkan pada halaman penambahan Kategori seperti pada **Gambar 2.4.2**.

<img src="/img/commerce/masterdata/category2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.4.2 Halaman Add Category
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Duplicate Category|Formulir Category akan terisi Otomatis berdasarkan data yang sudah terdaftar|Tekan tombol Duplicate Category|

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Type|Menentukan jenis atau klasifikasi kategori yang akan dibuat.|Ya
|Name|Nama dari kategori yang akan dibuat.|Ya

2. **`Isilah data penambahan Category`** lalu tekan tombol ***Submit***.
