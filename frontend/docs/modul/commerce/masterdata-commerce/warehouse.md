:::note
**`Menu ini digunakan untuk mendata, mengelola, dan mengorganisasi lokasi gudang dalam perusahaan. `** Warehouse adalah tempat penyimpanan barang/material, baik untuk bahan baku, barang setengah jadi, hingga barang jadi yang siap dikirim.

Halaman Warehouse dapat dilihat pada **Gambar 2.11.1**
:::

<img src="/img/commerce/masterdata/wh1.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.11.1 Halaman Warehouse
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah Gudang.|Tekan tombol Add Warehouse.|
|Download|Mengunduh Gudang dalam format file .xls atau .csv.|Tekan tombol Download.|
|Upload|Mengunggah Gudang dari file dengan format .xlsx, .xls, atau .csv.|Tekan tombol Upload.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Details|Melihat informasi mengenai gudang secara lebih rinci.|Tekan tombol Details pada kolom Action.
|Edit|Menyunting Gudang.|Tekan tombol Edit pada kolom Action.|
|Delete|Menghapus Gudang.|Tekan tombol Delete pada kolom Action.|
|Multiple Delete|Menghapus beberapa Gudang sekaligus.|Pilih Gudang baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Warehouse ?`

**`Berikut petunjuk dalam menambahkan Gudang :`**

1. **`Tekan tombol`** ***Add Warehouse*** dan pengguna akan diarahkan pada halaman penambahan Gudang seperti pada **Gambar 2.11.2**.

<img src="/img/commerce/masterdata/wh2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.11.2 Halaman Add Warehouse
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Duplicate Warehouse|Formulir Warehouse akan terisi Otomatis berdasarkan data yang sudah terdaftar|Tekan tombol Duplicate Warehouse|

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Name|Nama atau kode identitas unik untuk Gudang.|Ya
|Code|Kode unik yang digunakan untuk mengidentifikasi baris data stok atau entri gudang secara sistematis.|Ya
|Location|Lokasi fisik atau logis di mana barang disimpan dalam gudang.|Ya
|Department|Departemen yang memiliki, menggunakan, atau bertanggung jawab terhadap stok tersebut.|Tidak
|Product|Nama atau kode produk/barang yang disimpan di lokasi tersebut.|Tidak
|Stock|Jumlah barang yang tersedia saat ini di lokasi tersebut.|Tidak
|Minimum Stock|Batas minimum jumlah stok yang harus tersedia agar tidak kehabisan|Tidak

2. **`Isilah data penambahan Warehouse`** lalu tekan tombol ***Submit***.
