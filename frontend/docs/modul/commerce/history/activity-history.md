:::note
**`Halaman ini digunakan untuk merekam seluruh aktivitas atau riwayat tindakan yang dilakukan oleh pengguna (user) terhadap data atau dokumen dalam sistem, seperti Sales Order, Invoice, Delivery Note, Quotation, dsb.`**

Halaman menu Activity History dapat dilihat pada **Gambar 8.2.1**.
:::

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Download|Mengunduh data riwayat seluruh aktivitas yang sedang ditampilkan di halaman, dalam format seperti Excel (.xlsx) atau CSV.|Tekan tombol Download
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
