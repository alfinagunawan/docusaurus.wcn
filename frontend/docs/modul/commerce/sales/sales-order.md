:::note
**`Menu ini digunakan untuk membuat pesanan resmi dari customer setelah mereka menyetujui quotation (penawaran harga).`**

Halaman Sales Order dapat dilihat pada **Gambar 7.3.1**.
:::

<img src="/img/commerce/sales/so1.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 7.3.1 Halaman Sales Order
</p>

:::danger perlu diingat
Hanya ***Quotation*** dengan status ***Approve*** yang dapat diproses pada menu ini.
:::

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Details|Melihat data sales order secara lebih rinci.|Tekan tombol Details pada kolom Action.|
|Delete|Menghapus data sales order.|Tekan ikon sampah pada kolom Action.|
|Multiple Delete|Menghapus beberapa data sales order sekaligus.|Pilih data sales order baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Setuju & Tolak `Sales Order ?`

**`Petunjuk menyetujui dan menolak Sales Order : `**

1. **`Tekan tombol`** ***Details*** dan pengguna akan diarahkan pada halaman details data Sales Order seperti pada **Gambar 7.3.3**.

<img src="/img/commerce/sales/so2.png" alt="Deskripsi gambar" class="center" />
<img src="/img/commerce/sales/so3.png" alt="Deskripsi gambar" class="center" />
<img src="/img/commerce/sales/so4.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 7.3.3 Halaman Details Sales Order
</p>

2. **`Tentukan Sales Order`** dengan menekan tombol ***Approve*** untuk menyetujui atau ***Reject*** untuk menolak.

## Pembatalan `Sales Order ?`

:::note
**`Proses untuk membatalkan pesanan penjualan yang sebelumnya telah dibuat`** dalam sistem. Ini biasanya dilakukan jika terjadi ***kesalahan input, perubahan rencana, atau transfer tidak jadi dilakukan*** dengan syarat proses pesanan penjualan **`belum dilakukan proses lebih lanjut`**.
:::

**`Berikut petunjuk dalam melakukan pembatalan Sales Order :`**

1. **`Tekan tombol`** ***Details*** dan pengguna akan diarahkan pada halaman details data Sales Order seperti pada **Gambar 7.3.4**.

<img src="/img/commerce/sales/so5.png" alt="Deskripsi gambar" class="center" />
<img src="/img/commerce/sales/so6.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 7.3.4 Tombol Cancel Halaman Details Sales Order
</p>

2. **`Tekan tombol`** ***Cancel*** lalu proses Sales Order telah dibatalkan.
