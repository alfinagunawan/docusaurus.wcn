:::note
**`Menu Parameter digunakan untuk mendefinisikan kriteria penilaian atau indikator evaluasi yang nantinya akan digunakan pada menu Evaluation.`** Setiap parameter berfungsi sebagai acuan dalam proses evaluasi terhadap entitas tertentu, seperti supplier, dan customer.

Halaman Parameter dapat dilihat pada **Gambar 4.1.1**.
:::

<img src="/img/commerce/evaluation/parameter1.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 4.1.1 Halaman Parameter
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah parameter.|Tekan tombol Add Parameter.|
|Download|Mengunduh parameter dalam format file .xls atau .csv.|Tekan tombol Download.|
|Upload|Mengunggah parameter dari file dengan format .xlsx, .xls, atau .csv.|Tekan tombol Upload.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Details|Melihat informasi mengenai parameter secara lebih rinci.|Tekan tombol Details pada kolom Action.
|Edit|Menyunting parameter.|Tekan tombol Edit pada kolom Action.|
|Delete|Menghapus parameter.|Tekan tombol Delete pada kolom Action.|
|Multiple Delete|Menghapus beberapa parameter sekaligus.|Pilih parameter baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Parameter ?`

**`Berikut petunjuk dalam menambahkan Parameter :`**

1. **`Tekan tombol`** ***Add Parameter*** dan pengguna akan diarahkan pada halaman penambahan data Parameter seperti pada **Gambar 4.1.2**.

<img src="/img/commerce/evaluation/parameter2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 4.1.2 Halaman Add Parameter
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Duplicate Parameter|Formulir Parameter akan terisi Otomatis berdasarkan data yang sudah terdaftar|Tekan tombol Duplicate Parameter|

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Name|Nama parameter yang digunakan dalam proses evaluasi.|Ya
|Code|Kode unik untuk identifikasi internal parameter.|Ya
|Type|	Jenis parameter, biasanya menunjukkan kategori atau ruang lingkupnya.|Ya
|Description|	Penjelasan singkat mengenai tujuan atau definisi parameter tersebut agar tidak disalahartikan oleh evaluator.|Tidak

2. **`Isilah data penambahan Parameter`** lalu tekan tombol ***Submit***.
