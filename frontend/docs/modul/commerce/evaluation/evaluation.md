:::note
**`Menu Evaluation digunakan untuk melakukan eavluasi penilaian kinerja terhadap entitas tertentu supplier atau customer.`**

Halaman Evaluation dapat dilihat pada **Gambar 4.2.1**.
:::

<img src="/img/commerce/evaluation/evaluation1.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 4.2.1 Halaman Evaluation
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah evaluasi.|Tekan tombol Add Evaluation.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Details|Melihat informasi mengenai evaluasi secara lebih rinci.|Tekan tombol Details pada kolom Action.
|Edit|Menyunting evaluasi.|Tekan tombol Edit pada kolom Action.|
|Delete|Menghapus evaluasi.|Tekan tombol Delete pada kolom Action.|
|Multiple Delete|Menghapus beberapa evaluasi sekaligus.|Pilih evaluasi baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Evaluation ?`

**`Berikut petunjuk dalam menambahkan Evaluation :`**

1. **`Tekan tombol`** ***Add Evaluation*** dan pengguna akan diarahkan pada halaman penambahan data Evaluation seperti pada **Gambar 4.2.2**.

<img src="/img/commerce/evaluation/evaluation2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 4.2.2 Halaman Add Evaluation
</p>

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Type|Menentukan jenis entitas yang akan dievaluasi, apakah entitas tersebut merupakan ***Customer*** atau ***Supplier***.|Ya
|Description|Catatan atau penjelasan tambahan mengenai konteks atau hasil evaluasi secara umum.|Tidak

2. **`Isilah`** ***Type*** dari evaluasi yang akan dibuat, kemudian sistem akan menampilkan form isian tambahan seperti yang ditunjukan pada **Gambar 4.2.3**.

<img src="/img/commerce/evaluation/evaluation3.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 4.2.3 Form Isian Tambahan Evaluasi
</p>

3. **`Isilah data penambahan Evaluation`** lalu tekan tombol ***Submit***.

## Setuju & Tolak `Evaluation ?`

**`Berikut petunjuk dalam melakukan setuju & tolak Evaluation :`**

1. **`Tekan tombol`** ***Details*** dan pengguna akan diarahkan pada halaman details data Evaluation seperti pada **Gambar 4.2.4**.

<img src="/img/commerce/evaluation/evaluation4.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 4.2.4 Halaman Details Evaluation
</p>

2. **`Tentukan hasil evaluasi`** dengan menekan tombol ***Approve*** untuk menyetujui atau ***Reject*** untuk menolak.
