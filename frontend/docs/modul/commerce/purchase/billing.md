:::note
**`Menu ini digunakan untuk mencatat dan mengelola tagihan pembelian dari supplier berdasarkan transaksi pembelian yang sudah terjadi — seperti Purchase Order, Good Receipt, atau Expense.`**

Halaman Billing dapat dilihat pada **Gambar 6.7.1**.
:::

Gambar 6.7.1 Halaman Billing
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah data tagihan.|Tekan tombol Add Billing.|
|Download|Mengunduh data tagihan dalam format file .xls atau .csv.|Tekan tombol Download.|
|Upload|Mengunggah data tagihan dari file dengan format .xlsx, .xls, atau .csv.|Tekan tombol Upload.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Details|Melihat data tagihan secara lebih rinci.|Tekan tombol Details pada kolom Action.
|Edit|Menyunting data tagihan.|Tekan tombol Edit pada kolom Action.
|Delete|Menghapus data tagihan.|Tekan ikon sampah pada kolom Action.|
|Multiple Delete|Menghapus beberapa data tagihan sekaligus.|Pilih data tagihan baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Billing ?`

**`Berikut petunjuk dalam menambahkan Billing :`**

1. **`Tekan tombol`** ***Add Billing*** dan pengguna akan diarahkan pada halaman penambahan data tagihan seperti pada **Gambar 6.7.2**.

<img src="/img/commerce/purchase/billing2.png" alt="Deskripsi gambar" class="center" />
<img src="/img/commerce/purchase/billing3.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 6.7.2 Halaman Add Billing
</p>

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Supplier|Nama pemasok yang mengeluarkan tagihan.|Ya
|Currency|Mata uang yang digunakan pada invoice/tagihan.|Ya
|Posting Date|Tanggal pencatatan billing ke dalam sistem.|Ya
|Received Date|Tanggal invoice/tagihan diterima dari supplier.|Ya
|Contract Number|Nomor kontrak yang menjadi dasar transaksi (jika ada kontrak formal).|Tidak
|PO Number|Nomor Purchase Order yang terkait dengan billing ini.|Tidak
|Term of Payment|Syarat pembayaran yang disepakati dengan supplier.|Tidak
|Invoice Number|Nomor invoice resmi dari supplier.|Tidak
|Due Date|Tanggal jatuh tempo pembayaran invoice sesuai Term of Payment.|Tidak
|Tax Invoice Number|Nomor faktur pajak dari supplier.|Tidak
|Tax Invoice Date|Tanggal penerbitan faktur pajak.|Tidak
|Tax Invoice Type|Jenis faktur pajak yang diterbitkan/digunakan pada transaksi.|Tidak
|Good Receipt|Nomor dokumen penerimaan barang (GRN).|Tidak
|Products|Detail produk/jasa yang ditagihkan.|
|Note|Catatan umum terkait billing.|Tidak
|Remark|Keterangan singkat/penanda khusus.|Tidak
|Internal Note|Catatan untuk internal perusahaan.|Tidak
|File|Lampiran dokumen pendukung billing.|Tidak

2. **`Isilah data penambahan Billing`** lalu tekan tombol ***Submit***.
