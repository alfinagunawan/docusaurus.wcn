## Download `Report ?`

**`Berikut petunjuk dalam mengunduh Report  :`**

1. **`Isiilah data terkait pengunduhan report`** lalu tekan tombol ***Download***.

|Isian|Deskripsi|
|--|--|
|Customer|Pilihan untuk menampilkan laporan yang hanya terkait dengan customer tertentu.
|Supplier|Pilihan untuk menampilkan laporan khusus untuk supplier tertentu.
|Start Date|Tanggal awal periode laporan.
|End Date|Tanggal akhir periode laporan.
|Report Template|Format atau jenis laporan yang ingin ditampilkan.
