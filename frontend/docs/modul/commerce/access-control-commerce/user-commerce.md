:::note
**`Menu ini digunakan untuk mengelola data pengguna sistem`**. Hubungan Role dan User : 

- ***Role*** → mendefinisikan **apa yang bisa dilakukan**.
- ***User*** → siapa yang menggunakan sistem dan **apa yang boleh dia lakukan** tergantung dari role-nya.

Halaman menu User dapat dilihat pada **Gambar 9.2.1**.
:::

Gambar 9.2.1 Halaman User
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah pengguna.|Tekan tombol Add User.
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Edit|Menyunting pengguna.|Tekan tombol Edit pada kolom Action.
|Delete|Menghapus data pengguna.|Tekan tombol Delete pada kolom Action.
|Multiple Delete|Menghapus beberapa pengguna sekaligus.|Pilih pengguna yang ingin dihapus dengan cara menekan baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `User ?`

**`Berikut petunjuk dalam menambahkan User  :`**

1. **`Tekan tombol`** ***Add User*** dan pengguna akan diarahkan pada halaman penambahan pengguna seperti pada **Gambar 9.2.2.**

<img src="/img/commerce/access-control/user2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 9.2.2 Halaman Add User
</p>

|Isian|Deskripsi|
|--|--|
|Name|Nama dari user yang akan ditambahkan.|
|Role|Role atau peran dari user, dipilih dari daftar role yang sudah dibuat sebelumnya di menu Role.
|Position|Jabatan atau posisi pekerjaan dari user di organisasi.
|Email|Alamat email dari user yang bersangkutan.
|Password|Kata sandi untuk akun user yang akan dibuat.

2. **`Isiilah data terkait penambahan User`** lalu tekan tombol ***Submit***.
