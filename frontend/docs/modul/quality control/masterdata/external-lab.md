|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah External Lab.|Tekan tombol Add External Lab.|
|Download|Mengunduh External Lab dalam format file .xls atau .csv.|Tekan tombol Download.|
|Upload|Mengunggah External Lab dari file dengan format .xlsx, .xls, atau .csv.|Tekan tombol Upload.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Edit|Menyunting External Lab.|Tekan tombol Edit pada kolom Action.|
|Delete|Menghapus External Lab.|Tekan tombol Delete pada kolom Action.|
|Multiple Delete|Menghapus beberapa External Lab sekaligus.|Pilih External Lab baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `External Lab ?`

**`Berikut petunjuk dalam menambahkan External Lab :`**

1. **`Tekan tombol`** ***Add External Lab*** dan pengguna akan diarahkan pada halaman penambahan External Lab seperti pada **Gambar 2.6.2**.

<img src="/img/qc/masterdata/external2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.6.2 Halaman Add External Lab
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Duplicate External Lab|Formulir External Lab akan terisi Otomatis berdasarkan data yang sudah terdaftar|Tekan tombol Duplicate External Lab|

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Name|Nama pengujian atau sampel yang dikirim ke lab.|Ya
|Alias|Nama singkat atau kode internal untuk mempermudah pencarian di sistem.|Ya
|Type|Tipe pengujian : ***Contaminant*** → untuk pengujian bahan pencemar kimia atau fisik (misalnya pestisida, residu pelarut, aflatoksin). ***Microbiological*** → untuk pengujian mikroorganisme (misalnya E. coli, Salmonella, TPC). ***Trace Metal*** → untuk pengujian logam berat (misalnya Pb, Hg, As, Cd).|Ya
|Specification|Standar acuan atau batas maksimum yang diperbolehkan (sesuai regulasi atau kontrak).|Ya
|Result|Hasil aktual yang dilaporkan oleh external lab.|Ya
|Testing Period|Tanggal atau periode kapan pengujian dilakukan atau sampel dikirim.|Ya
|Vendor Tester|Nama pihak ketiga yang melakukan pengujian.

2. **`Isilah data penambahan External Lab`** lalu tekan tombol ***Submit***.
