|Fitur|Deskripsi|Cara Akses|

|Download|Mengunduh Sample Code dalam format file .xls atau .csv.|Tekan tombol Download.|
|Upload|Mengunggah Sample Code dari file dengan format .xlsx, .xls, atau .csv.|Tekan tombol Upload.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Edit|Menyunting Sample Code.|Tekan tombol Edit pada kolom Action.|
|Delete|Menghapus Sample Code.|Tekan tombol Delete pada kolom Action.|
|Multiple Delete|Menghapus beberapa Sample Code sekaligus.|Pilih Sample Code baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Sample Code ?`

**`Berikut petunjuk dalam menambahkan Sample Code :`**

1. **`Tekan tombol`** ***Add Sample Code*** dan pengguna akan diarahkan pada halaman penambahan Sample Code seperti pada **Gambar 2.9.2**.

<img src="/img/qc/masterdata/sample2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.9.2 Halaman Add Sample Code
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Duplicate Sample Code|Formulir Sample Code akan terisi Otomatis berdasarkan data yang sudah terdaftar|Tekan tombol Duplicate Sample Code|

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Name|Nama deskriptif sampel.|Ya
|Code|Kode unik yang merepresentasikan sampel tersebut.|Ya

2. **`Isilah data penambahan Sample Code`** lalu tekan tombol ***Submit***.
