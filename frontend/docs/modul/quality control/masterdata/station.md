Halaman Station dapat dilihat pada **Gambar 2.5.1**
:::

Gambar 2.5.1 Halaman Station

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah station.|Tekan tombol Add Station.|
|Download|Mengunduh station dalam format file .xls atau .csv.|Tekan tombol Download.|
|Upload|Mengunggah station dari file dengan format .xlsx, .xls, atau .csv.|Tekan tombol Upload.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Edit|Menyunting station.|Tekan tombol Edit pada kolom Action.|
|Delete|Menghapus station.|Tekan tombol Delete pada kolom Action.|
|Multiple Delete|Menghapus beberapa station sekaligus.|Pilih station baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Station ?`

**`Berikut petunjuk dalam menambahkan Station :`**

1. **`Tekan tombol`** ***Add Station*** dan pengguna akan diarahkan pada halaman penambahan Station seperti pada **Gambar 2.5.2**.

<img src="/img/qc/masterdata/station2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.5.2 Halaman Add Station
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Duplicate Station|Formulir Station akan terisi Otomatis berdasarkan data yang sudah terdaftar|Tekan tombol Duplicate Station|

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Name|Nama station QC.|Ya
|Code|Kode unik untuk station.|Ya
|Category|Kategori station sesuai fungsi atau lokasi di proses produksi.|Ya
|Product|Produk yang diuji di station tersebut.|Ya

2. **`Isilah data penambahan Station`** lalu tekan tombol ***Submit***.
