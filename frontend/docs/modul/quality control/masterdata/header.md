Halaman Header dapat dilihat pada **Gambar 2.7.1**
:::

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah Header.|Tekan tombol Add Header.|
|Download|Mengunduh Header dalam format file .xls atau .csv.|Tekan tombol Download.|
|Upload|Mengunggah Header dari file dengan format .xlsx, .xls, atau .csv.|Tekan tombol Upload.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Edit|Menyunting Header.|Tekan tombol Edit pada kolom Action.|
|Delete|Menghapus Header.|Tekan tombol Delete pada kolom Action.|
|Multiple Delete|Menghapus beberapa Header sekaligus.|Pilih Header baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Header ?`

**`Berikut petunjuk dalam menambahkan Header :`**

1. **`Tekan tombol`** ***Add Header*** dan pengguna akan diarahkan pada halaman penambahan Header seperti pada **Gambar 2.7.2**.

<img src="/img/qc/masterdata/header2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.7.2 Halaman Add Header
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Duplicate Header|Formulir Header akan terisi Otomatis berdasarkan data yang sudah terdaftar|Tekan tombol Duplicate Header|

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Name|Nama header atau judul kelompok data.|Ya
|Type|Cara Pengisian : ***Input Manual*** → Nilai dimasukkan bebas oleh pengguna (operator QC mengetik langsung angkanya atau keterangan). ***Fixed*** → Nilai sudah ditentukan tetap (otomatis muncul, tidak bisa diubah).***Fixed with Dropdown List*** → Pilihan sudah ditentukan dalam bentuk daftar pilihan, operator tinggal memilih.|Ya

2. **`Isilah data penambahan Header`** lalu tekan tombol ***Submit***.
