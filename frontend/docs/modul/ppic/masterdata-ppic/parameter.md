|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah parameter.|Tekan tombol Add Parameter.|
|Download|Mengunduh parameter dalam format file .xls atau .csv.|Tekan tombol Download.|
|Upload|Mengunggah parameter dari file dengan format .xlsx, .xls, atau .csv.|Tekan tombol Upload.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Edit|Menyunting parameter.|Tekan tombol Edit pada kolom Action.|
|Delete|Menghapus parameter.|Tekan tombol Delete pada kolom Action.|
|Multiple Delete|Menghapus beberapa parameter sekaligus.|Pilih parameter baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Parameter ?`

**`Berikut petunjuk dalam menambahkan Parameter :`**

1. **`Tekan tombol`** ***Add Parameter*** dan pengguna akan diarahkan pada halaman penambahan Parameter seperti pada **Gambar 2.2.2**.

<img src="/img/ppic/masterdata/parameter2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.2.2 Halaman Add Parameter
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Duplicate Parameter|Formulir Parameter akan terisi Otomatis berdasarkan data yang sudah terdaftar|Tekan tombol Duplicate Parameter|

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Category|Kategori atau kelompok parameter.|Ya
|Name|Nama dari parameter. Merupakan identitas atau label yang menjelaskan maksud parameter tersebut.|Ya
|UoM|Satuan dari nilai parameter yang akan dimasukkan.|Tidak

2. **`Isilah data penambahan Parameter`** lalu tekan tombol ***Submit***.
