:::note refining
**`Halaman ini digunakan untuk mengelola aktivitas produksi/refining produk minyak (seperti RBD Palm Oil, Blended Oil, Refined Soybean Oil, dll.) pada berbagai lini produksi (production line).`** Menu ini penting dalam proses perencanaan, eksekusi, dan pemantauan proses refining.

Halaman Refining dapat dilihat pada **Gambar 3.5.1.1**.
:::

<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 3.5.1.1 Halaman Refining
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah data refining.|Tekan tombol Add refining.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Release Production Order|Mengonversi rencana produksi (Refining Plan) yang sudah disetujui (Approved) menjadi perintah produksi resmi yang siap dijalankan oleh tim produksi di lapangan.|Tekan tombol Release Production Order
|Details|Melihat data refining secara lebih rinci.|Tekan tombol Details pada kolom Action.
|Edit|Menyunting data refining.|Tekan tombol Edit pada kolom Action.
|Approve|Menyetujui data refining.|Tekan tombol Approve pada kolom Action.
|Cancel|Membatalkan data refining.|Tekan tombol Cancel pada kolom Action.
|Delete|Menghapus data refining.|Tekan ikon sampah pada kolom Action.|
|Multiple Delete|Menghapus beberapa data refining sekaligus.|Pilih data refining baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Refining ?`

**`Berikut petunjuk dalam menambahkan Refining :`**

1. **`Tekan tombol`** ***Add Refining*** dan sistem akan menampilkan pop up penambahan Refining seperti pada **Gambar 3.5.1.2**.

<img src="/img/ppic/apps/plantrf2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 3.5.1.2 Halaman Add Refining
</p>

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Product|produk yang akan diproses dalam batch produksi refining tersebut.|Ya
|Quantity (ton)|total volume produksi untuk produk refining yang akan dihasilkan, dinyatakan dalam ton.|Ya
|Production Line|Jalur produksi atau unit mesin yang akan digunakan untuk menjalankan proses refining.|Ya

2. **`Isilah data penambahan Refining`** lalu tekan tombol ***Submit***.

## Setuju & Tolak `Refining ?`

**`Berikut petunjuk dalam melakukan setuju & tolak Refining :`**

1. **`Tekan tombol`** ***Approve*** untuk menyetujui plant refining dan ***Reject*** untuk menolak plant refining pada kolom Action seperti pada **Gambar 3.5.1.3**.

<img src="/img/ppic/apps/plantrf3.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 3.5.1.3 Tombol Approve dan Reject
</p>

2. **`Tekan tombol`** ***Release Production Order*** pada kolom Action untuk mengonversi rencana produksi (***plant refining***) yang sudah disetujui menjadi perintah produksi resmi seperti yang ditunjukan pada **Gambar 3.5.1.4**.
