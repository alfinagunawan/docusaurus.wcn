:::note
Menu ini digunakan untuk ***mencatat data penggunaan atau realisasi parameter pendukung pada suatu Production Line di tanggal tertentu***.

Halaman menu Utility dapat dilihat pada **Gambar 3.7.1**.
:::

<img src="/img/ppic/apps/utility1.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 3.7.1 Halaman Menu Utility
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah Utility.|Tekan tombol Add Utility|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Edit|Menyunting data Utility.|Tekan tombol Edit pada kolom Action.
|Approve|Menyetujui data Utility.|Tekan tombol Approve pada kolom Action.
|Cancel|Membatalkan data Utility.|Tekan tombol Cancel pada kolom Action.
|Delete|Menghapus data Utility.|Tekan ikon sampah pada kolom Action.|
|Multiple Delete|Menghapus beberapa data Utility sekaligus.|Pilih data Utility baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Utility ?`

**`Berikut petunjuk dalam menambahkan Utility :`**

1. **`Tekan tombol`** ***Add Utility*** dan pengguna akan diarahkan ke halaman penambahan Utility seperti pada **Gambar 3.7.2**.

<img src="/img/ppic/apps/utility2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 3.7.2 Halaman Add Utility
</p>

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Production Line|Memilih jalur produksi yang akan dicatat data utilitasnya.|Ya
|Date|Menentukan tanggal pencatatan.|Ya
|Realization (Parameter, Unit, Value)| Berisi daftar parameter yang diukur atau dicatat |Tidak

2. **`Isilah data terkait penambahan Utility`** lalu tekan tombol ***Submit***.

## Setuju & Tolak `Utility ?`

**`Berikut petunjuk dalam melakukan setuju & tolak Utility :`**

1. **`Tekan tombol`** ***Approve*** untuk menyetujui Utility dan ***Reject*** untuk menolak Utility pada kolom Action seperti pada **Gambar 3.7.3**.
