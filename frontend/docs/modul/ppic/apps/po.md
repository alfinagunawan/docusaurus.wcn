Halaman Purchase Order dapat dilihat pada **Gambar 3.2.1**.

Gambar 3.2.1 Halaman Purchase Order

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah data pesanan pembelian.|Tekan tombol Add Purchase Order.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|View|Melihat data pesanan pembelian secara lebih rinci.|Tekan tombol Details pada kolom Action.
|Approve|Menyetujui data pesanan pembelian.|Tekan tombol Approve pada kolom Action.
|Reject|Menolak data pesanan pembelian.|Tekan tombol Reject pada kolom Action.
|Edit|Menyunting data pesanan pembelian.|Tekan tombol Edit pada kolom Action.
|Delete|Menghapus data pesanan pembelian.|Tekan ikon sampah pada kolom Action.|
|Multiple Delete|Menghapus beberapa data pesanan pembelian sekaligus.|Pilih data pesanan pembelian baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Purchase Order ?`

**`Berikut petunjuk dalam menambahkan Purchase Order :`**

1. **`Tekan tombol`** ***Add Purchase Order*** dan pengguna akan diarahkan pada halaman penambahan data pesanan pembelian seperti pada **Gambar 3.2.2**.

<img src="/img/ppic/apps/po2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 3.2.2 Halaman Add Purchase Order
</p>

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Supplier|Nama vendor atau penyedia barang/jasa yang akan dihubungi.|Ya
|Delivery Date|Tanggal yang diharapkan untuk pengiriman barang dari supplier ke lokasi tujuan (gudang/pabrik).|Ya
|Product|Produk atau barang yang akan dibeli dalam PO ini.|Tidak

2. **`Isilah data penambahan pesanan pembelian`** lalu tekan tombol ***Submit***.

## Setuju & Tolak `Purchase Order ?`

**`Berikut petunjuk dalam melakukan setuju & tolak Purchase Order :`**

1. **`Tekan tombol`** ***Approve*** untuk menyetujui purchase order dan tombol ***Reject*** untuk menolak purchase order pada kolom Action seperti pada **Gambar 3.2.3**.

<img src="/img/ppic/apps/po3.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 3.2.3 Tombol Approve dan Reject
</p>

## Terima `Purchase Order ?`

**`Berikut petunjuk dalam terima barang Purchase Order :`**

1. **`Tekan tombol`** ***Mark as Received*** untuk menandai purchase order tersebut telah dilakukan penerimaan barang pada kolom Action seperti pada **Gambar 3.2.4**.

<img src="/img/ppic/apps/po4.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 3.2.4 Tombol Mark as Received
</p>

## Tutup `Purchase Order ?`

**`Berikut petunjuk dalam menutup Purchase Order :`**

1. **`Tekan tombol`** ***Closed PO*** untuk menutup PO secara manual ketika proses pemesanan dinyatakan selesai pada kolom Action seperti pada **Gambar 3.2.5**.
