Halaman Sales Order dapat dilihat pada **Gambar 3.3.1**.
:::

<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 3.3.1 Halaman Sales Order

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah data pesanan penjualan.|Tekan tombol Add Purchase Order.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|View|Melihat data pesanan penjualan secara lebih rinci.|Tekan tombol Details pada kolom Action.
|Edit|Menyunting data pesanan penjualan.|Tekan tombol Edit pada kolom Action.
|Delivered|Menandai bahwa pesanan (SO) telah dikirimkan.|Tekan tombol Delivered pada kolom Action.
|Delete|Menghapus data pesanan penjualan.|Tekan ikon sampah pada kolom Action.|
|Multiple Delete|Menghapus beberapa data pesanan penjualan sekaligus.|Pilih data pesanan penjualan baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Sales Order ?`

**`Berikut petunjuk dalam menambahkan Sales Order :`**

1. **`Tekan tombol`** ***Add Sales Order*** dan pengguna akan diarahkan pada halaman penambahan data pesanan penjualan seperti pada **Gambar 3.3.2**.

<img src="/img/ppic/apps/so2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 3.3.2 Halaman Add Sales Order
</p>

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Customer|Pelanggan yang melakukan pemesanan.|Ya
|Requested Date|Tanggal permintaan dari pelanggan terkait kapan produk atau layanan sebaiknya disiapkan atau dikirim.|Ya
|Delivery Date|Tanggal yang direncanakan untuk pengiriman produk kepada pelanggan.|Tidak
|Product|Produk atau item yang dipesan oleh pelanggan.|Ya

2. **`Isilah data penambahan pesanan penjualan`** lalu tekan tombol ***Submit***.

## Kirim `Sales Order ?`

**`Berikut petunjuk dalam pengiriman barang Sales Order :`**

1. **`Tekan tombol`** ***Delivered*** untuk menandai sales order tersebut telah dilakukan pengiriman barang pada kolom Action seperti pada **Gambar 3.3.3**.

<img src="/img/ppic/apps/so3.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>

</p>

## Tutup `Sales Order ?`

**`Berikut petunjuk dalam menutup Sales Order :`**

1. **`Tekan tombol`** ***Close*** untuk menutup SO secara manual ketika proses pemesanan dinyatakan selesai pada kolom Action seperti pada **Gambar 3.3.4**.
