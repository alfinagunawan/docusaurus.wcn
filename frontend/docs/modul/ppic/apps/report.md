:::note
Menu ini digunakan untuk ***menampilkan rangkuman data produksi berdasarkan jalur produksi (Production Line) dan periode bulanan yang dipilih***.

Halaman menu Report dapat dilihat pada **Gambar 3.8.1**.
:::

<img src="/img/ppic/apps/report1.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 3.8.1 Halaman Menu Report
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Production Line|Memilih jalur produksi tertentu agar laporan hanya menampilkan data terkait line tersebut.|Pilih data dari daftar dropdown Production Line
|Period|Memilih bulan tertentu untuk melihat data produksi yang terjadi di periode tersebut.|Pilih data dari daftar dropdown Period

2. **`Isilah pilihan dropdown Production Line dan Period`**, lalu sistem akan menampilkan ***Report Preview*** seperti yang ditunjukan pada Ga**mbar 3.8.2**.
