:::note
**`Menu ini digunakan untuk memperbarui data persediaan (inventory) minyak atau produk lain yang tersimpan di dalam tangki. `**

Halaman Inventory dapat dilihat pada **Gambar 3.1.1**.
:::

<img src="/img/monitoring/apps/inventory1.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 3.1.1 Halaman Inventory
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Update Sounding|Pembaruan data sounding pada menu Inventory.|Tekan tombol Update Sounding.|
|Download|Mengunduh data inventory.|Tekan tombol Donwload
|Upload|Mengunggah data inventory.|Tekan tombol Upload
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|

## Update `Sounding ?`

**`Berikut petunjuk dalam pembaruan data Sounding :`**

1. **`Tekan tombol`** ***Update Sounding*** dan pengguna akan diarahkan pada halaman pembaruan data sounding seperti pada **Gambar 3.1.2**.

<img src="/img/monitoring/apps/inventory2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 3.1.2 Halaman Update Sounding
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Save|Menyimpan perubahan data sounding atau kolom lainnya ke dalam sistem.|Tekan tombol Save
|Cancel|Membatalkan perubahan yang telah dilakukan sebelum disimpan.|Tekan tombol Cancel

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Sounding|Hasil pengukuran manual (sounding) volume isi tangki dalam ton.|Tidak
|QC|Mencatat status atau hasil pemeriksaan kualitas produk (Quality Control).|Tidak
|Origin|Sumber atau asal produk dalam tangki tersebut.|Tidak
|Remarks|Catatan tambahan terkait kondisi tangki atau produk.|Tidak
|Highlight|Menandai baris data tertentu agar lebih mudah ditemukan atau diprioritaskan.|Tidak

2. **`Isilah data pembaruan Inventory`** lalu tekan tombol ***Save***.
