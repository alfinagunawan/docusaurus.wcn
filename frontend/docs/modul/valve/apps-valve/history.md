:::note
**`Menu History berfungsi untuk menampilkan riwayat proses unloading yang telah dilakukan`**. Dalam tampilan ini, pengguna dapat melihat informasi lengkap terkait setiap transaksi pembongkaran muatan. 

Halaman menu History dapat dilihat pada **Gambar 2.2**.
:::

Gambar 2.2 Halaman History
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Download|Mengunduh data riwayat transaksi dalam format excel|Tekan tombol Download
|Filter|Menyaring data berdasarkan kriteria tertentu.|Tekan tombol Filter
|Reset Filter|Menghapus filter yang sudah diterapkan dan menampilkan seluruh data kembali.|Tekan tombol Reset Filter
