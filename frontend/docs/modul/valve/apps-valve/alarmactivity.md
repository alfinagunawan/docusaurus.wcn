:::note
**`Menu Alarm / Activity Log berfungsi untuk mencatat dan menampilkan seluruh kejadian penting serta notifikasi sistem`** yang berkaitan dengan proses unloading. 

Halaman menu Alarm / Activity Log dapat dilihat pada **Gambar 2.3**.
:::

<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.3 Halaman Alarm / Activity Log
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Download|Mengunduh data riwayat transaksi dalam format excel|Tekan tombol Download
|Filter|Menyaring data berdasarkan kriteria tertentu.|Tekan tombol Filter
|Reset Filter|Menghapus filter yang sudah diterapkan dan menampilkan seluruh data kembali.|Tekan tombol Reset Filter
|ACK|Mengirim sinyal ke PLC untuk mematikan bunyi alarm|Tekan tombol ACK
