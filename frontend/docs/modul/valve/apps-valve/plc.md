:::note
**`Menu PLC Test berfungsi untuk melakukan pengujian konektifitas dan fungsi kontrol antara aplikasi dan perangkat PLC`** (***Programmable Logic Controller***). 

Halaman PLC Test dapat dilihat pada **Gambar 2.4**.
:::

<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.4 Halaman PLC Test
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Read|**Membaca nilai** dari address yang telah dimasukkan.|Tekan tombol Read
|Write|**Mengirim perintah penulisan nilai ke PLC**.|Tekan tombol Write

|Isian|Deskripsi|
|--|--|
|Address|**Alamat register** atau ***I/O address*** di PLC yang ingin diakses.
|Write Value|**Nilai yang akan dikirim** (ditulis) ke address PLC yang ditentukan.
|Result|Menampilkan hasil dari proses pembacaan atau penulisan.
