# Valve
:::note tujuan
**`Memantau dan mengelola proses pembongkaran muatan (unloading)`** dari kendaraan secara real-time untuk memastikan proses distribusi CPO dan CNO berjalan lancar, aman, dan efisien. Modul ini memungkinkan pengguna mengontrol aliran produk dari kendaraan ke tangki penyimpanan dengan pemantauan aktivitas pompa dan alarm yang terintegrasi.
:::

### `Petunjuk Penggunaan`
1. **`Mengelola Data Master Sistem`** : Gunakan menu Master Data (seperti Color, Line, Pump, Unloading Station, Product Type, Tank, dan Valve Pump) untuk memasukkan atau memperbarui data infrastruktur sistem unloading. Data ini menjadi fondasi utama dalam pengoperasian sistem pompa dan valve.
2. **`Melakukan Proses Unloading`** : Melalui menu Apps > Unloading, pengguna dapat memulai proses pembongkaran muatan dari kendaraan ke tangki.
3. **`Memantau Riwayat Aktivitas Sistem`** : Di menu History, pengguna dapat melihat rekaman semua aktivitas unloading, alarm, dan pergerakan valve secara kronologis. Ini penting untuk audit dan pelacakan performa sistem.

:::danger Tips dan Trik
1. **`Periksa Alarm dan Aktivitas Secara Berkala`** : Pastikan Anda rutin memeriksa tab Alarm dan Activity untuk mendeteksi jika ada anomali atau penghentian sistem secara tidak normal. Hal ini penting untuk menjaga keamanan proses unloading.
2. **`Pastikan Data Tangki dan Jalur Valid`** : Sebelum memulai unloading, pastikan tangki dan jalur yang dipilih aktif dan sesuai dengan jenis produk. Kesalahan pemilihan bisa menyebabkan pencampuran produk atau kegagalan proses.
3. **`Gunakan Mode Maintenance Saat Dibutuhkan`** : Saat dilakukan inspeksi atau pemeliharaan, aktifkan Maintenance Mode agar tidak terjadi aktivitas otomatis yang tidak diinginkan.
:::
