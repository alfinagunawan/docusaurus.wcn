:::note
**`Menu Unloading Station digunakan untuk memantau, mengatur, dan mengelola proses pembongkaran muatan (unloading)`** dari kendaraan pengangkut seperti truk tangki ke tangki penyimpanan atau jalur produksi.

Halaman menu Unloading Station dapat dilihat pada **Gambar 1.4.1**.
:::

<img src="/img/valve/masterdata/unloading 1.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 1.4.1 Halaman Menu Unloading Station
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah stasiun pembongkaran muatan.|Tekan tombol Add Unloading Station.|
|Download|Mengunduh stasiun pembongkaran muatan dalam format file .xls atau .csv.|Tekan tombol Download.|
|Upload|Mengunggah stasiun pembongkaran muatan dari file dengan format .xlsx, .xls, atau .csv.|Tekan tombol Upload.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Edit|Menyunting stasiun pembongkaran muatan.|Tekan tombol Edit pada kolom Action.|
|Delete|Menghapus stasiun pembongkaran muatan.|Tekan tombol Delete pada kolom Action.|
|Multiple Delete|Menghapus beberapa stasiun pembongkaran muatan sekaligus.|Pilih stasiun pembongkaran muatan yang ingin dihapus dengan cara menekan baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Unloading Station ?`

**`Berikut petunjuk dalam menambahkan Unloading Station :`**

1. **`Tekan tombol`** ***Add Unloading Station*** dan pengguna akan diarahkan pada halaman penambahan stasiun pembongkaran muatan seperti pada **Gambar 1.4.1**.

<img src="/img/valve/masterdata/unloading 2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 1.4.1 Halaman Add Unloading Station
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Duplicate Unloading Station|Formulir Unloading Station akan terisi Otomatis berdasarkan data yang sudah terdaftar|Tekan tombol Duplicate Unloading Station|

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Name|Nama stasiun pembongkaran muatan.|Ya
|Pump|Pemilihan pompa yang terdapat pada stasiun tersebut.|Ya

2. **`Isilah data penambahan Unloading Station`** lalu tekan tombol ***Submit***.
