:::note
**`Menu Color digunakan untuk menentukan warna jalur pengisian tangki`**, yang berfungsi sebagai penanda visual dalam proses operasional. Pemilihan warna ini membantu pengguna dalam mengidentifikasi dan membedakan jalur pengisian dengan lebih mudah di tampilan aplikasi. 

Halaman menu Color dapat dilihat pada **Gambar 1.1**.
:::

<img src="/img/valve/masterdata/color 1.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 1.1 Halaman Menu Color
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah warna.|Tekan tombol Add Color.|
|Download|Mengunduh warna dalam format file .xls atau .csv.|Tekan tombol Download.|
|Upload|Mengunggah warna dari file dengan format .xlsx, .xls, atau .csv.|Tekan tombol Upload.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Edit|Menyunting warna.|Tekan tombol Edit pada kolom Action.|
|Delete|Menghapus warna.|Tekan tombol Delete pada kolom Action.|
|Multiple Delete|Menghapus beberapa warna sekaligus.|Pilih warna yang ingin dihapus dengan cara menekan baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Color ?`

**`Berikut petunjuk dalam menambahkan Color :`**

1. **`Tekan tombol`** ***Add Color*** dan pengguna akan diarahkan pada halaman penambahan warna seperti pada **Gambar 1.1.1**.

<img src="/img/valve/masterdata/color 2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 1.1.1 Halaman Add Color
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Duplicate Color|Formulir Color akan terisi Otomatis berdasarkan data yang sudah terdaftar|Tekan tombol Duplicate Color|

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Name|Nama warna.|Ya|
|Color|Menentukan warna.|Ya|

2. **`Isilah data penambahan Color`** lalu tekan tombol ***Submit***.
