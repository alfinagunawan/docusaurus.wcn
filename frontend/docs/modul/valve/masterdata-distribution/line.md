:::note
**`Menu Line digunakan untuk menambahkan dan mengelola jalur pengisian tangki yang digunakan dalam proses pemindahan produk`**. Jalur ini dapat mewakili pipa atau saluran fisik yang menghubungkan antara sumber dan tangki tujuan.

Halaman menu Line dapat dilihat pada **Gambar 1.2**.
:::

<img src="/img/valve/masterdata/line 1.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 1.2 Halaman Menu Line
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah jalur.|Tekan tombol Add Line.|
|Download|Mengunduh jalur dalam format file .xls atau .csv.|Tekan tombol Download.|
|Upload|Mengunggah jalur dari file dengan format .xlsx, .xls, atau .csv.|Tekan tombol Upload.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Edit|Menyunting jalur.|Tekan tombol Edit pada kolom Action.|
|Delete|Menghapus jalur.|Tekan tombol Delete pada kolom Action.|
|Multiple Delete|Menghapus beberapa jalur sekaligus.|Pilih jalur yang ingin dihapus dengan cara menekan baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Line ?`

**`Berikut petunjuk dalam menambahkan Line :`**

1. **`Tekan tombol`** ***Add Line*** dan pengguna akan diarahkan pada halaman penambahan jalur seperti pada **Gambar 1.2.1**.

<img src="/img/masterdata/driver/driver 2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 1.2.1 Halaman Add Line
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Duplicate Line|Formulir Line akan terisi Otomatis berdasarkan data yang sudah terdaftar|Tekan tombol Duplicate Line|

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Name|Nama jalur.|Ya|
|Color|Menentukan jalur.|Ya

2. **`Isilah data penambahan Line`** lalu tekan tombol ***Submit***.
