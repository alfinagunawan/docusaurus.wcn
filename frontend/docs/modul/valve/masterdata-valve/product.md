:::note
**`Menu Product Type digunakan untuk mengelompokkan produk`** berdasarkan jenis atau kategori tertentu.

Halaman menu Product Type dapat dilihat pada **Gambar 1.5.1**.
:::

<img src="/img/valve/masterdata/product 1.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 1.5.1 Halaman Menu Product Type
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah tipe produk.|Tekan tombol Add Product Type.|
|Download|Mengunduh tipe produk dalam format file .xls atau .csv.|Tekan tombol Download.|
|Upload|Mengunggah tipe produk dari file dengan format .xlsx, .xls, atau .csv.|Tekan tombol Upload.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Edit|Menyunting tipe produk.|Tekan tombol Edit pada kolom Action.|
|Delete|Menghapus tipe produk.|Tekan tombol Delete pada kolom Action.|
|Multiple Delete|Menghapus beberapa tipe produk sekaligus.|Pilih tipe produk yang ingin dihapus dengan cara menekan baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Product Type ?`

**`Berikut petunjuk dalam menambahkan Product Type :`**

1. **`Tekan tombol`** ***Add Product Type*** dan pengguna akan diarahkan pada halaman penambahan tipe produk seperti pada **Gambar 1.5.1**.

<img src="/img/valve/masterdata/product 2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 1.5.1 Halaman Add Product Type
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Duplicate Product Type|Formulir Product Type akan terisi Otomatis berdasarkan data yang sudah terdaftar|Tekan tombol Duplicate Product Type|

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Name|Nama tipe produk.|Ya
|Description|Deskripsi secara singkat mengenai fungsi atau karakteristik dari tipe produk yang dimaksud|Ya

2. **`Isilah data penambahan Product Type`** lalu tekan tombol ***Submit***.
