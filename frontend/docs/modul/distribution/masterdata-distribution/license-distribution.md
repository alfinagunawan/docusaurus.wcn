:::note
**`Menu License digunakan untuk mengelola data perizinan kendaraan`** yang digunakan dalam proses distribusi. Halaman menu License dapat dilihat pada **Gambar 2.1.1**.
:::

<img src="/img/masterdata/license/license 1.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.1.1 Halaman Menu License
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah lisensi.|Tekan tombol Add License.|
|Download|Mengunduh lisensi dalam format file .xls atau .csv.|Tekan tombol Download.|
|Upload|Mengunggah lisensi dari file dengan format .xlsx, .xls, atau .csv.|Tekan tombol Upload.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Edit|Menyunting lisensi.|Tekan tombol Edit pada kolom Action.|
|Delete|Menghapus lisensi.|Tekan tombol Delete pada kolom Action.|
|Multiple Delete|Menghapus beberapa lisensi sekaligus.|Pilih lisensi yang ingin dihapus dengan cara menekan baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `License ?`

**`Berikut petunjuk dalam menambahkan License :`**

1. **`Tekan tombol`** ***Add License*** dan pengguna akan diarahkan pada halaman penambahan lisensi seperti pada **Gambar 2.1.1.1**.

<img src="/img/masterdata/license/license 2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.1.1.1 Halaman Add License
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Duplicate License|Formulir License akan terisi Otomatis berdasarkan data yang sudah terdaftar|Tekan tombol Duplicate License|

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Name|Nama lisensi.|Ya|
|Description|Catatan deskripsi terkait lisensi.|Tidak|

2. **`Isilah data penambahan License`** lalu tekan tombol ***Submit***.
