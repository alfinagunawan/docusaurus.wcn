:::

<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.6.1 Halaman Menu Supplier

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah pemasok.|Tekan tombol Add Supplier.|
|Download|Mengunduh pemasok dalam format file .xls atau .csv.|Tekan tombol Download.|
|Upload|Mengunggah pemasok dari file dengan format .xlsx, .xls, atau .csv.|Tekan tombol Upload.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Details|Melihat data pemasok secara rinci.|Tekan tombol Details pada kolom Action.
|Edit|Menyunting pemasok.|Tekan tombol Edit pada kolom Action.|
|Delete|Menghapus pemasok.|Tekan tombol Delete pada kolom Action.|
|Multiple Delete|Menghapus beberapa pemasok sekaligus.|Pilih pemasok yang ingin dihapus dengan cara menekan baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Supplier ?`

**`Berikut petunjuk dalam menambahkan Supplier :`**

1. **`Tekan tombol`** ***Add Supplier*** dan pengguna akan diarahkan pada halaman penambahan pemasok seperti pada **Gambar 2.6.1.1**.

<img src="/img/masterdata/supplier/supplier 2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.6.1.1 Halaman Add Supplier
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Duplicate Supplier|Formulir Supplier akan terisi Otomatis berdasarkan data yang sudah terdaftar|Tekan tombol Duplicate Supplier|

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Name|Nama pemasok.|Ya
|ID|Nomor unik pemasok.|Ya
|Address|Alamat pemasok.|Tidak

2. **`Isilah data penambahan Supplier`** lalu tekan tombol ***Submit***.
