**`Menu Customer digunakan untuk mengelola data pelanggan`**. Halaman menu Customer dapat dilihat pada Gambar 2.5.1.
:::

<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.5.1 Halaman Menu Customer

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah pelanggan.|Tekan tombol Add Customer.|
|Download|Mengunduh pelanggan dalam format file .xls atau .csv.|Tekan tombol Download.|
|Upload|Mengunggah pelanggan dari file dengan format .xlsx, .xls, atau .csv.|Tekan tombol Upload.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Details|Melihat data pelanggan secara rinci.|Tekan tombol Details pada kolom Action.
|Edit|Menyunting pelanggan.|Tekan tombol Edit pada kolom Action.|
|Delete|Menghapus pelanggan.|Tekan tombol Delete pada kolom Action.|
|Multiple Delete|Menghapus beberapa pelanggan sekaligus.|Pilih pelanggan yang ingin dihapus dengan cara menekan baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Customer ?`

**`Berikut petunjuk dalam menambahkan Customer :`**

1. **`Tekan tombol`** ***Add Customer*** dan pengguna akan diarahkan pada halaman penambahan pelanggan seperti pada **Gambar 2.5.1.1**.

<img src="/img/masterdata/customer/customer 2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.5.1.1 Halaman Add Customer
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Duplicate Customer|Formulir Customer akan terisi Otomatis berdasarkan data yang sudah terdaftar|Tekan tombol Duplicate Customer|

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Name|Nama pelanggan.|Ya
|ID|Nomor unik pelanggan.|Ya
|Type|Tipe pelanggan: ***Local*** : pilih ini jika pelanggan berada di dalam negeri (lokal). ***Export*** : pilih ini jika pelanggan berasal dari luar negeri (ekspor).|Tidak
|Address|Alamat pelanggan.|Tidak

2. **`Isilah data penambahan Customer`** lalu tekan tombol ***Submit***.
