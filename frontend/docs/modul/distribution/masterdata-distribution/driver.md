:::note
**`Menu Driver digunakan untuk mengelola data sopir (driver)`** yang terlibat dalam proses distribusi. Halaman menu License dapat dilihat pada **Gambar 2.2.1**.
:::

<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.2.1 Halaman Menu Driver
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah sopir.|Tekan tombol Add License.|
|Download|Mengunduh sopir dalam format file .xls atau .csv.|Tekan tombol Download.|
|Upload|Mengunggah sopir dari file dengan format .xlsx, .xls, atau .csv.|Tekan tombol Upload.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Driver Type|Jenis kepemilikan dari sopir (WCN/NON WCN)|Tekan selektor pada WCN/NON WCN
|Edit|Menyunting sopir.|Tekan tombol Edit pada kolom Action.|
|Delete|Menghapus sopir.|Tekan tombol Delete pada kolom Action.|
|Multiple Delete|Menghapus beberapa sopir sekaligus.|Pilih sopir yang ingin dihapus dengan cara menekan baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Driver ?`

**`Berikut petunjuk dalam menambahkan Driver :`**

1. **`Tekan tombol`** ***Add Driver*** dan pengguna akan diarahkan pada halaman penambahan sopir seperti pada **Gambar 2.2.1.1**.

<img src="/img/masterdata/driver/driver 2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.2.1.1 Halaman Add License
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Duplicate Driver|Formulir Driver akan terisi Otomatis berdasarkan data yang sudah terdaftar|Tekan tombol Duplicate Driver|

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Name|Nama sopir.|Ya|
|Driver ID|Nomor identifikasi unik untuk sopir yang digunakan secara internal oleh sistem.|Ya|
|Driver License Type|Jenis SIM yang dimiliki driver (contoh: SIM A, SIM B1, SIM B2).|Ya
|Driver License|Nomor dari SIM (Surat Izin Mengemudi) driver.|Ya
|Ownership|**Status kepemilikan driver**, terdapat dua opsi: ***WCN*** : Driver adalah **pegawai tetap** perusahaan. ***NON WCN*** : Driver adalah **tenaga pihak ketiga** dari mitra/vendor.|Ya

2. **`Isilah data penambahan Driver`** lalu tekan tombol ***Submit***.
