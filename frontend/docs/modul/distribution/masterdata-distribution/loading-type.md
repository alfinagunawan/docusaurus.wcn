:::note
**`Menu Loading Type digunakan untuk mengelola  jenis-jenis aktivitas bongkar muat`** atau perpindahan barang yang terjadi dalam proses operasional, seperti pengiriman, penerimaan, retur, dan lainnya. Halaman menu Loading Type dapat dilihat pada **Gambar 2.7.1**.
:::

Gambar 2.7.1 Halaman Menu Loading Type

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Download|Mengunduh data jenis aktivitas bongkar muat dalam format file .xls atau .csv.|Tekan tombol Download.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Edit|Menyunting data jenis aktivitas bongkar muat.|Tekan tombol Edit pada kolom Action.|

## Sunting `Loading Type ?`

**`Berikut petunjuk dalam menyunting Loading Type :`**

1. Tekan tombol ***Edit*** pada kolom action dan pengguna akan diarahkan pada halaman sunting data jenis aktivitas bongkar muat seperti pada **Gambar 2.7.1.1**.

<img src="/img/masterdata/loading/loading 2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.7.1.1 Halaman Edit Loading Type
</p>

|Isian|Deskripsi|
|--|--|
|Type|Merupakan kode singkat untuk jenis loading.
|Description|Keterangan atau nama lengkap dari jenis loading.
|SBO Required|Digunakan untuk menentukan apakah dokumen SBO (Surat Bongkar Order) wajib disertakan.
|Weighbridge Condition|Aturan terkait berat timbangan masuk dan keluar kendaraan.
|Customer or Supplier|Menentukan siapa yang terlibat dalam aktivitas loading ini.
|Seal Required|Menentukan apakah informasi segel (seal) perlu ditampilkan.

2. **`Isilah data peyuntingan Loading Type`** lalu tekan tombol ***Submit***.
