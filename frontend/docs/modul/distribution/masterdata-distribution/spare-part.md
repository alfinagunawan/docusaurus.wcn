:::note
**`Menu Spare part digunakan untuk mengelola data semua suku cadang (spare part)`** yang digunakan dalam operasional perusahaan, baik untuk kendaraan, mesin, maupun alat lainnya. Halaman menu Spare part dapat dilihat pada **Gambar 2.8.1**.
:::

<img src="/img/masterdata/sparepart/sparepart 1.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.8.1 Halaman Menu Spare Part
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah spare part.|Tekan tombol Add Spare Part.|
|Download|Mengunduh spare part dalam format file .xls atau .csv.|Tekan tombol Download.|
|Upload|Mengunggah spare part dari file dengan format .xlsx, .xls, atau .csv.|Tekan tombol Upload.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Edit|Menyunting spare part.|Tekan tombol Edit pada kolom Action.|
|Delete|Menghapus spare part.|Tekan tombol Delete pada kolom Action.|
|Multiple Delete|Menghapus beberapa spare part sekaligus.|Pilih spare part yang ingin dihapus dengan cara menekan baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Spare Part ?`

**`Berikut petunjuk dalam menambahkan Spare Part :`**

1. **`Tekan tombol`** ***Add Spare Part*** dan pengguna akan diarahkan pada halaman penambahan spare Part seperti pada **Gambar 2.8.1.1**.

<img src="/img/masterdata/sparepart/sparepart 2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.8.1.1 Halaman Add Spare Part
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Duplicate Spare Part|Formulir Spare Part akan terisi Otomatis berdasarkan data yang sudah terdaftar|Tekan tombol Duplicate Spare Part|

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Category|Kelompok atau jenis dari spare part.|Ya
|Name|Nama atau identitas utama dari spare part.|Ya
|Description|Penjelasan tambahan tentang spare part, biasanya berisi spesifikasi atau informasi teknis.|Tidak
|Stock Limit|Batas minimal stok yang harus tersedia di gudang.|Ya
|Price|Harga pembelian satuan dari spare part tersebut.|Ya

2. **`Isilah data penambahan Spare Part`** lalu tekan tombol ***Submit***.
