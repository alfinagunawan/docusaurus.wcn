:::note
**`Menu Expense Type digunakan untuk mencatat dan mengelompokkan jenis-jenis pengeluaran (biaya)`** yang terjadi dalam operasional perusahaan, terutama yang berkaitan dengan kendaraan, alat, atau aktivitas logistik. Halaman menu Expense Type dapat dilihat pada **Gambar 2.9.1**.
:::

<img src="/img/masterdata/expense/expense 1.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.9.1 Halaman Menu Expense Type
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah jenis pengeluaran.|Tekan tombol Add Expense Type.|
|Download|Mengunduh jenis pengeluaran dalam format file .xls atau .csv.|Tekan tombol Download.|
|Upload|Mengunggah jenis pengeluaran dari file dengan format .xlsx, .xls, atau .csv.|Tekan tombol Upload.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Edit|Menyunting jenis pengeluaran.|Tekan tombol Edit pada kolom Action.|
|Delete|Menghapus jenis pengeluaran.|Tekan tombol Delete pada kolom Action.|
|Multiple Delete|Menghapus beberapa jenis pengeluaran sekaligus.|Pilih jenis pengeluaran yang ingin dihapus dengan cara menekan baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Expense Type ?`

**`Berikut petunjuk dalam menambahkan Expense Type :`**

1. **`Tekan tombol`** ***Add Expense Type*** dan pengguna akan diarahkan pada halaman penambahan jenis pengeluaran seperti pada **Gambar 2.9.1.1**.

<img src="/img/masterdata/expense/expense 2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.9.1.1 Halaman Add Expense Type
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Duplicate Expense Type|Formulir Expense Type akan terisi Otomatis berdasarkan data yang sudah terdaftar|Tekan tombol Duplicate Expense Type|

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Category|Kelompok atau jenis dari pengeluaran.|Ya
|Name|Nama atau identitas utama dari jenis pengeluaran.|Ya
|Description|Penjelasan tambahan tentang jenis pengeluaran.|Tidak

2. **`Isilah data penambahan Expense Type`** lalu tekan tombol ***Submit***.
