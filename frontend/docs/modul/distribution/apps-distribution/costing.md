:::note
**`Menu Costing digunakan untuk mencatat, mengelola, dan menganalisis biaya-biaya`** yang berkaitan dengan kegiatan operasional, khususnya yang berhubungan dengan maintenance, atau aktivitas logistik lainnya.. Halaman menu Costing dapat dilihat pada **Gambar 3.6.1**.
:::

<img src="/img/apps/costing/costing 1.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 3.6.1 Halaman Costing
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Add|Menambah biaya.|Tekan tombol Add Maintenance.
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Details|Melihat data biaya secara rinci.|Tekan tombol Details pada kolom Action.
|Edit|Menyunting biaya.|Tekan tombol Edit pada kolom Action.
|Delete|Menghapus data biaya.|Tekan tombol Delete pada kolom Action.
|Multiple Delete|Menghapus beberapa biaya sekaligus.|Pilih biaya yang ingin dihapus dengan cara menekan baris atau dengan mencentang kotak pada sebelah kiri. Kemudian tekan tombol Multiple  Delete (berwarna merah).|

## Tambah `Costing ?`

**`Berikut petunjuk dalam menambahkan Costing  :`**

1. **`Tekan tombol`** ***Add Costing*** dan pengguna akan diarahkan pada halaman penambahan biaya seperti pada **Gambar 3.6.1.1**.
