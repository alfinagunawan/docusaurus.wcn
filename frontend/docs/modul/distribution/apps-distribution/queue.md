:::note
**`Menu Queue digunakan untuk antrian kendaraan atau distribusi berdasarkan prioritas atau status antrian`**. Halaman menu Queue dapat dilihat pada **Gambar 3.3.1**.
:::

<img src="/img/apps/queue/queue 1.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 3.3.1 Halaman Menu Queue
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|Set Auth||Tekan tombol Set Auth.|
|Filter|Menyaring data dengan kondisi tertentu|Tekan tombol Filter.|
|Reset Filter|Mengembalikan data pada kondisi semula|Tekan tombol Reset Filter.|
|Details|Melihat data queue secara rinci.|Tekan tombol Details pada kolom Action.
|Done|Menyelesaikan antrian kendaraan.|Tekan tombol Done pada kolom Action.|
|Cancel|Membatalkan antrian kendaraan.|Tekan tombol Cancel pada kolom Action.

## Set Auth Column Queue

Halaman menu ***Set Auth Column Queue*** dapat dilihat pada **Gambar 3.3.1.1**

<img src="/img/apps/queue/queue 2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 3.3.1.1 Halaman Menu Set Auth Column Queue
</p>

|Isian|Deskripsi|Wajib Diisi|
|--|--|--|
|Role|Dropdown untuk memilih **peran pengguna** (misalnya: Admin, Security, Checker, Driver Supervisor).|Ya
|Role Column Permissions|Berisi daftar kolom yang dapat ditampilkan atau disembunyikan untuk role yang dipilih. Setiap kolom memiliki checkbox "***View***" yang bisa dicentang atau tidak.|Ya
