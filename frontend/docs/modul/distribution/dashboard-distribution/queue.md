:::note
**`Halaman ini digunakan untuk menampilkan antrean kendaraan atau distribusi`** berdasarkan prioritas atau status antrian. Halaman menu Dashboard Queue dapat dilihat pada **Gambar 1.3**.
:::

Gambar 1.3 Halaman Dashboard Queue
</p>

|Fitur|Deskripsi|Cara Akses|
|--|--|--|
|History|Riwayat rencana pengiriman yang telah dilakukan sebelumnya. Saat tombol ini ditekan, sistem akan mengarahkan halaman pada menu Apps > Queue|Tekan tombol History.|
|Filter|Menyaring atau membatasi data yang ditampilkan berdasarkan kondisi tertentu.|Tekan tombol Filter.|
|Reset Filter|Mengembalikan tampilan data ke kondisi default (tanpa filter).|Tekan tombol Reset Filter.|

|Data Dashboard|Deskripsi|
|--|--|
|Queue In|Menampilkan kendaraan baru masuk ke sistem antrian dan belum menjalani proses distribusi lebih lanjut.|
|On Progress|Menampilkan kendaraan sedang dalam proses operasional aktif di area distribusi.|
|Checked Out|Menampilkan kendaraan telah menyelesaikan seluruh proses distribusi dan keluar dari sistem antrian.|
