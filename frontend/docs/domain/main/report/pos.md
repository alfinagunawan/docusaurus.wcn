:::note
- **`Menu ini merupakan hasil rekap transaksi dari sistem Point of Sale (POS)`** dalam periode "Last Month" (Bulan Lalu). 
- **`Laporan ini mencakup total penjualan`**, **jumlah produk terjual**, **rata-rata pendapatan per transaksi**, serta **detail transaksi individual** 

Halaman Report Transaksi POS dapat dilihat pada **Gambar 5.1.1**. 
:::

<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 5.1.1. Halaman Report POS
</p>

| Fitur | Deskripsi | Cara Akses |
| -------- | --- | --- |
| View Details | Melihat informasi laporan lebih rinci  | Tekan tombol Details (ikon mata) pada kolom Action |
| Download | Mengunduh daftar laporan dalam format file .xls atau .csv. | Tekan tombol Download |
| Select Date Range | Menyaring daftar list laporan sesuai dengan jangka waktu| Pilih pada kolom Select Date Range|

## Fitur Lanjutan 
:::note
Pada halaman, fitur "**v**" dapat dipergunakan untuk melihat detail Invoice terkait ***proses penjualan pada POS***. 
- Tekan tombol "**v**" dan sistem akan menampilkan detail Invoice seperti pada gambar dibawah ini.
