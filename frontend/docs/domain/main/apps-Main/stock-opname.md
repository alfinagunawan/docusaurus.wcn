## Tambah `Stock Opname?`
Dalam menambahkan data Stock Opname hanya dapat dilakukan oleh pengguna yang berperan sebagai **Super Admin** atau peran yang diberikan hak akses untuk melakukan ***add*** (tambah), ***view*** (melihat), dan ***edit*** (menyunting) data. Penambahan peran atau hak akses dapat dilihat pada menu [**Role**](/docs/domain/main/access-control/role.md) . 

**`Petunjuk penambahan Stock Opname :`** 
- `Tekan tombol add Stock Opname` : Pengguna akan diarahkan ke halaman penambahan Stock Opname dapat dilihat pada **Gambar 3.4.2.**

<img src="/img/main/so4.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 3.4.2. Halaman Add Stock Opname
</p>

| Isian | Deskripsi |
| -------- | --- |
|  Warehouse| Menentukan gudang yang akan melakukan pemeriksaan. |
| Item list  | Daftar barang yang tersedia pada gudang tersebut |
| Estimate | Estimasi stok pada sistem |
| Actual | Kuantitas stok yang sebenarnya di lapangan (Dengan ini pengguna dapat membandingkan kuantitas antara stok estimasi dengan stok aktual yang sebenarnya di lapangan) |
| Note | Catatan barang |

| Fitur | Deskripsi |
| -------- | --- |
| Draft | Menyimpan laporan stock opname sementara, dan masih bisa melakukan edit/sunting data |
| Save | Menyimpan laporan stock opname yang sudah benar |

- **`Tentukan aktual stok barang`**, lalu tekan tombol ***Save/Draft***.
