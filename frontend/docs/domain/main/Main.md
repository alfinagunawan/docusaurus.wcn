# Main
:::note tujuan
**`Mengelola data utama`** terkait proses bisnis, seperti barang, gudang, target capaian bisnis serta pengelolaan kontrol akses aplikasi.
:::

### `Petunjuk Penggunaan`
1. **`Menambah Data Master`** : Panduan akan menjelaskan langkah - langkah untuk
menambahkan data pada menu Master Data.
2. **`Kontrol Akses Aplikasi`** : Petunjuk akan memberikan instruksi mengenai cara
menggunakan menu akses kontrol. Ini termasuk menambahkan peran selaku pengguna
bisnis, serta akses dari peran menggunakan email yang terdaftar.

:::danger Tips dan Trik
1. **`Cek Ketersediaan Stok di Lapangan`** : Pastikan untuk selalu memeriksa ketersediaan stok di lapangan, dengan tujuan untuk membandingkan data barang antara persedian dilapangan dan hasil input di aplikasi. Langkah - langkah yang diberikan telah ditulis secara rinci pada panduan.
2. **`Konversi Satuan Barang`** : Memanfaatkan fitur konversi barang untuk melakukan
konversi guna memenuhi kebutuhan bisnis, konversi dapat dilakukan barang yang sama dengan satuan yang berbeda, dengan artian barang dapat dipecah menjadi satuan kecil, atau dikemas menjadi satuan yang besar
:::
