## Tambah `User?`
Dalam menambahkan data User hanya dapat dilakukan oleh pengguna yang berperan sebagai **Super Admin** atau peran yang diberikan hak akses untuk melakukan ***add*** (tambah), ***view*** (melihat), dan ***edit*** (menyunting) data. Penambahan peran atau hak akses dapat dilihat pada menu [**Role**](/docs/domain/commerce/access-control-Commerce/role-Commerce.md) .

**`Petunjuk penambahan User :`** 
- `Tekan tombol add User` : Pengguna akan diarahkan ke halaman penambahan user dapat dilihat pada **Gambar 4.3.2.**
<img src="/img/commerce/user3.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 4.3.2 Halaman add user
</p>

| Fitur | Deskripsi | Cara Akses |
| -------- | --- | --- |
| Duplicate User | Formulir User akan terisi Otomatis berdasarkan data yang sudah terdaftar | Tekan tombol Duplicate User |

| Isian | Deskripsi | Wajib Diisi | Persyaratan |
| -------- | --- | --- | --- |
| First Name | Nama awal pengguna | Ya | Tidak ada |
| Last Name | Nama akhir pengguna | Ya | Tidak ada |
| Role | Hak akses pengguna | Ya | Role harus terdaftar di menu Role |
| Email | Email pengguna | Ya | Tidak ada |
| Password | Password pengguna | Ya | Tidak ada |

- `Isilah data terkait Penambahan user`, lalu tekan tombol **submit**.

## User Melebihi Batas ?

:::note
<img src="/img/commerce/user2.png" alt="Deskripsi gambar" class="center" />

- `Jika muncul popup seperti di atas`, pengguna harus menyelesaikan pembayaran terlebih dahulu untuk menambahkan user baru dengan menekan tombol ***Add More User***.

- `Lakukan pembayaran dan tunggu persetujuan dari admin`. Setelah disetujui, pengguna dapat menambahkan user baru kembali.
:::
