## Tambah `Tax ?`
Dalam menambahkan data Tax hanya dapat dilakukan oleh pengguna yang berperan sebagai **Super Admin** atau peran yang diberikan hak akses untuk melakukan ***add*** (tambah), ***view*** (melihat), dan ***edit*** (menyunting) data. Penambahan peran atau hak akses dapat dilihat pada menu [**Role**](/docs/domain/main/access-control/role.md). 

**`Petunjuk penambahan tax :`** 
- `Tekan tombol add tax` : Pengguna akan diarahkan ke halaman penambahan pajak seperti pada **Gambar 2.10.2**.

| Fitur | Deskripsi | Cara Akses |
| -------- | --- | --- |
| Duplicate Tax | Formulir Tax Isi Otomatis berdasarkan data yang sudah terdaftar | Tekan tombol Duplicate Tax |

| Isian | Deskripsi | Wajib Diisi |
| -------- | --- | --- |
| Name | Nama Pajak | Ya |
| Percentage | Persentase Pajak | Ya |
| Code | Kode Pajak | Ya |
| Description | Catatan deskripsi pajak | Tidak |

- `Isilah data terkait penambahan tax`, lalu tekan tombol **submit**.
