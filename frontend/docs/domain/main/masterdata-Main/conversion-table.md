:::note
Tabel Konversi dibuat secara otomatis berdasarkan UoM terdaftar. 
- **`Pengukuran dengan satuan standar`**, akan dihitung otomatis oleh sistem.
- **`Pengukuran dengan satuan custom`**, pengguna perlu menyunting konversi sesuai dengan kebutuhan bisnis.
- Data yang disimpan akan digunakan dalam menu **`Convert Item`** sebagai faktor pengali.
- Halaman Conversion Table dapat dilihat pada **Gambar 2.3.1**.

## Sunting `Conversion Table ?`
Dalam menyunting data tabel konversi hanya dapat dilakukan oleh pengguna yang berperan sebagai **Super Admin** atau peran yang diberikan hak akses untuk melakukan ***edit*** (menyunting) data. Penambahan peran atau hak akses dapat dilihat pada menu [**Role**](/docs/domain/main/access-control/role.md) . 

**`Petunjuk penyuntingan Conversion Table :`** 
- `Tekan tombol edit` lalu mengisi nilai konversi pada kolom tersedia, dimana pengguna bebas menentukan konversi dari satu unit ke unit lainnya seperti pada **Gambar 2.3.3**
<img src="/img/main/conversion3.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.3.3. Edit Conversion Table
</p>

- `Tekan tombol Save` bila proses penyuntingan selesai. Data yang disimpan akan digunakan dalam ***Convert Item*** sebagai faktor pengali.
- `Tekan tombol Cancel` bila proses penyuntingan dibatalkan.
- `Tekan tombol Swap` untuk menukar posisi tabel.
