## Tambah `Location ?`
Dalam menambahkan data Location hanya dapat dilakukan oleh pengguna yang berperan sebagai **Super Admin** atau peran yang diberikan hak akses untuk melakukan ***add*** (tambah), ***view*** (melihat), dan ***edit*** (menyunting) data. Penambahan peran atau hak akses dapat dilihat pada menu [**Role**](/docs/domain/main/access-control/role.md) . 

**`Petunjuk penambahan Location :`** 
- `Tekan tombol add location` : Pengguna akan diarahkan ke halaman penambahan lokasi dapat dilihat pada **Gambar 2.6.2.**
<img src="/img/main/lokasi2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.6.2. Halaman Add Location
</p>

| Fitur | Deskripsi | Cara Akses |
| -------- | --- | --- |
| Duplicate Location | Formulir Location akan terisi Otomatis berdasarkan data yang sudah terdaftar | Tekan tombol Duplicate Location |

| Isian | Deskripsi | Wajib Diisi |
| -------- | --- | --- |
| Name  | Nama lokasi | Ya |
| Address | Alamat lokasi | Ya |
| Latitude | Garis lintang lokasi | Tidak |
| Longitude | Garis bujur lokasi | Tidak |

- `Isilah data terkait penambahan location`, lalu tekan tombol ***submit***.
