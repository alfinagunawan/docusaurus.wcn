## Tambah `Station ?`

Dalam menambahkan data Station hanya dapat dilakukan oleh pengguna yang berperan sebagai **Super Admin** atau peran yang diberikan hak akses untuk melakukan ***add*** (tambah), ***view*** (melihat), dan ***edit*** (menyunting) data. Penambahan peran atau hak akses dapat dilihat pada menu [**Role**](/docs/domain/main/access-control/role.md). 

**`Petunjuk penambahan Station :`** 
- `Tekan tombol add Station` : Pengguna akan diarahkan ke halaman penambahan station seperti pada **Gambar 2.13.2.**

<img src="/img/main/station2.png" alt="Deskripsi gambar" class="center" />
<p style={{textAlign: 'center', fontSize: '0.8em'}}>
Gambar 2.13.2. Halaman Add Station
</p>

| Fitur | Deskripsi | Cara Akses |
| -------- | --- | --- |
| Duplicate Station | Formulir Station akan terisi Otomatis berdasarkan data yang sudah terdaftar | Tekan tombol Duplicate Station |

| Isian | Deskripsi | Wajib Diisi |
| -------- | --- | --- |
| Name | Nama station | Ya |
| Machine| Selektor untuk memilih mesin | Ya |
| Description |Catatan deskripsi station | Tidak |

- `Isilah data terkait penambahan station`, lalu tekan tombol ***Submit***.
