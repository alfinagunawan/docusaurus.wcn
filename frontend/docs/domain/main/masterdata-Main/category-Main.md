## Tambah `Category ?`
Dalam menambahkan data Category hanya dapat dilakukan oleh pengguna yang berperan sebagai **Super Admin** atau peran yang diberikan hak akses untuk melakukan ***add*** (tambah), ***view*** (melihat), dan ***edit*** (menyunting) data. Penambahan peran atau hak akses dapat dilihat pada menu [**Role**](/docs/domain/main/access-control/role.md) . 

**`Petunjuk penambahan category :`** 
- `Tekan tombol add category` : Pengguna akan diarahkan ke halaman penambahan kategori dapat dilihat pada **Gambar 2.1.2.**

<img src="/img/main/addcategory1.png" alt="Deskripsi gambar" class="center" />

</p>

| -------- | --- | --- |
| Duplicate Category | Formulir Category akan terisi Otomatis berdasarkan data yang sudah terdaftar | Tekan tombol Duplicate Category |

| Isian | Deskripsi | Wajib Diisi |
| -------- | --- | --- |
| Type  | Tipe barang (**Raw** / **BOM**). | Ya |
