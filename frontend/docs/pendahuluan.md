# Pendahuluan
:::tip  Dokumentasi
📝 Dokumentasi dirancang dengan pembahasan yang mudah dipahami dan terstruktur. Mari kita jelajahi `PhiBase.io`. 
:::

## Tinjauan Umum
`PhiBase.io` : Solusi Operasional End-to-End untuk Pengambilan Keputusan yang Tepat.

`Tujuan` : Membantu perusahaan Anda membangun basis data yang kuat dan meningkatkan kelincahan dalam pengambilan
keputusan.

`Struktur Domain` : Bekerja Sama Secara Mandiri

:::info  
**PhiBase.io** terbagi menjadi beberapa aplikasi terpisah yang disebut ***Domain***. Setiap domain memiliki fokus dan fitur-fitur yang berkaitan dengan operasi di area tertentu. 
:::

| Domain | Deskripsi |
| -------- | --- |
| Utama | Mengelola **data master**, transfer inventori, konversi item, dan lainnya. |
| Penjualan | Mendukung proses **penjualan** dan hubungan pelanggan. |
| Manufaktur | Manajemen proses **produksi** dan **manufaktur**. |
| Distribusi | Mengatur logistik dan **distribusi** produk. |
| Pemeliharaan | Menangani **perawatan** dan **perbaikan** aset. |
| Kontrol Kualitas  | Memastikan **kualitas produk** dan layanan. |
| Keuangan | Mengelola **keuangan** dan akuntansi perusahaan. |
| Laporan | Menyajikan **laporan** dan analisis data. |
| Penjadwalan | **Menjadwalkan** dan memantau aktivitas. |
| Analitik | Menyajikan **Analitik** data terhadap proses bisnis. |
|POS (***Point Of Sales***)|Mengelola **transaksi penjualan di titik penjualan**, termasuk pembayaran, pencatatan pesanan, dan integrasi dengan sistem persediaan.|

`Fleksibilitas dan Kemudahan Penggunaan` : Dirancang untuk Semua Perusahaan.

`Lebih dari Sekadar Data Mandiri` : Membangun Gambaran Utuh

Kemampuan analitik yang ditanamkan dalam PhiBase.io menggabungkan semua data mandiri dari berbagai domain menjadi satu data yang utuh. Hal ini memberikan gambaran akurat tentang apa, di mana, dan mengapa sesuatu terjadi dalam perusahaan Anda secara menyeluruh.

## Target Pengguna

:::tip  Siapa yang Harus Membaca Panduan Ini ?
Panduan pengguna ini ditujukan bagi `tim operasional` perusahaan Anda yang akan
menggunakan aplikasi PhiBase.io. Akan lebih baik jika ada satu orang dalam organisasi yang
memahami garis besar fitur-fitur yang tersedia untuk memaksimalkan penggunaannya.
:::

`Penggunaan Panduan` : **Disusun Berdasarkan Domain**

Panduan ini disusun berdasarkan domain, sehingga tim operasional hanya perlu membaca
bagian yang relevan dengan tugas mereka. Contohnya, tim operasional penjualan tidak perlu
membaca panduan domain distribusi untuk menggunakan domain commerce.
